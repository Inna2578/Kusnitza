# Кузница сюжетов (PWA)

Генератор завязок для фэнтези: герой, мир, магия, задача, срок, поворот и цена.
Работает без интернета после первого открытия, ставится на экран телефона.

## Как выложить на GitHub Pages

1. Создай репозиторий на github.com (например, `kuznitsa-syuzhetov`), публичный.
2. Загрузи в него всё содержимое этой папки: `index.html`, `manifest.webmanifest`, `sw.js` и папку `icons`.
   Файлы должны лежать в корне репозитория, не внутри вложенной папки.
3. В репозитории открой Settings, затем Pages. В Source выбери «Deploy from a branch»,
   ветку `main` и папку `/ (root)`. Сохрани.
4. Через минуту-две приложение откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/kuznitsa-syuzhetov/`.

## Как поставить на телефон

- **iPhone (Safari):** «Поделиться», затем «На экран "Домой"».
- **Android (Chrome):** меню «⋮», затем «Установить приложение» или «Добавить на главный экран».

## Как обновить

После правок в `index.html` измени номер в первой строке `sw.js`
(`kuznitsa-v1` на `kuznitsa-v2` и так далее). Тогда телефоны скачают новую версию.

Избранное хранится в самом браузере на каждом устройстве отдельно.
